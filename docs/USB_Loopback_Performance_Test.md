# USB Loopback 性能测试说明

## 测试目的

对比不同 MCU / USB 协议栈在 **USB 回环（Loopback）** 场景下的实际数据传输性能，为后续方案选型和性能优化提供依据。

## 测试条件

* **测试模式**：USB Loopback（Host 发送 → Device 原样返回）
* **单次数据量**：1 KB
* **统计方式**：单次往返时间（Round Trip Time）
* **测试环境**：PC 端发送 + 固件回环返回
* **数据单位**：毫秒（ms）

> 注：测试结果为多次实测的典型范围值，非理论极限。

## 测试结果

| 平台 / 协议栈     | USB 类型          | 1 KB 回环耗时       | 备注               |
| ------------ | --------------- | --------------- | ---------------- |
| STM32 + FUSB | FS (Full Speed) | **2 – 3 ms**    | USB FS硬件，速度不高 |
| STM32 + HUSB | HS (High Speed) | **0.5 – 1 ms**  | USB HS硬件，速度明显提升 |
| ESP32        | FS (USB OTG)    | **50 – 100 ms** | 软件栈和任务调度开销较大     |

## 结果分析

### STM32 + FUSB

* 基于 **USB Full Speed (12 Mbps)**
* 性能稳定，适合中低速控制类应用
* 1 KB 回环在 **2–3 ms** 属于正常范围

### STM32 + HUSB

* 基于 **USB High Speed (480 Mbps)**
* FIFO + DMA 优势明显
* 同样 1 KB 数据，时延下降到 **500 µs – 1 ms**
* 适合对吞吐和延迟敏感的应用

### ESP32 USB

* USB 栈主要运行在 **FreeRTOS 任务上下文**
* 调度延迟和软件开销较大
* 即使数据量不大，回环延迟仍达到 **50–100 ms**
* 不适合低延迟、高频通信场景

## 结论

* **低延迟 / 高频 USB 通信**：优先选择 **STM32 + HUSB**
* **普通控制 / 调试通信**：STM32 + FUSB 已足够
* **ESP32 USB**：更适合功能型或低频通信，不适合作为高速 USB 设备
