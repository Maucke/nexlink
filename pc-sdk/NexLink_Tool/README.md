# NexLink Tool

NexLink Tool 是一个基于 WPF 的桌面调试工具，用于与 NexLink 设备进行 USB 通信、指令发送、屏幕图像传输以及日志监控。

该工具属于 NexLink PC-SDK 的可视化调试前端。

---

# 功能简介

## 1️⃣ 设备管理

* 自动扫描已连接的 NexLink 设备
* 显示设备 Product 和 Serial
* 连接 / 断开设备
* 自动获取设备版本信息
* 自动时间同步
* 自动启动屏幕帧同步

---

## 2️⃣ 实时日志系统

支持设备主动上报的事件：

* 普通日志
* 警告信息
* 错误信息
* 心跳包

所有日志会：

* 显示时间戳
* 区分日志等级
* 同步弹出通知提示

---

## 3️⃣ 屏幕功能

### 屏幕实时同步

* 支持设备屏幕帧实时上传
* 自动拼接数据
* 自动转换为 Bitmap
* 在 UI 中实时显示

### 截图导出

* 可将当前显示画面保存为 PNG
* 自动生成时间戳文件名
* 保存路径：

```
程序目录/ScreenShot/
```

---

## 4️⃣ 指令系统

### 内置常用命令

默认提供：

* SYNC Time（时间同步）
* Reset（硬件复位）
* ScreenShot（请求帧）
* Up / Down / Enter / Exit（按键模拟）

---

### 自定义命令

支持：

* 新增命令
* 删除命令
* 拖拽排序
* 保存到本地工程文件

所有命令支持：

* 指令选择
* HEX 数据输入
* 一键发送
* 显示返回数据

---

## 5️⃣ 图像发送功能

支持：

* 选择 PNG / JPG / BMP
* 自动缩放到设备屏幕分辨率
* 自动转换为目标色深（Bpp）
* 发送至设备显示

---

## 6️⃣ 工程自动保存

程序关闭时自动保存：

* 自定义命令列表
* I2C 操作配置
* 命令顺序

保存文件：

```
config.proj
```

启动时自动加载。

---

# 软件架构说明

采用：

* MVVM 结构
* Prism 框架
* Wpf.Ui 现代 UI
* 事件驱动通信

核心模块：

* Home 页面（显示日志 + 屏幕）
* Command 页面（命令发送）
* Setting 页面（设备管理）

---

# 典型使用流程

1. 打开软件
2. 自动扫描设备
3. 选择设备并连接
4. 进入 Home 查看日志
5. 进入 Command 页面发送指令
6. 可实时查看屏幕
7. 可导出截图
8. 关闭时自动保存配置
