# NexLink Tool 使用说明书

---

# 1. 软件简介

**NexLink Tool** 是一款用于 **NexLink 设备调试与控制** 的桌面工具软件。

软件提供：

* 设备连接与管理
* 命令发送
* 屏幕实时显示
* 外设接口调试
* 日志查看

适用于：

* NexLink 显示设备开发
* 通信协议调试
* 外设接口测试
* 系统调试与验证

软件界面简洁，功能模块化，适合开发人员与测试人员使用。

---

# 2. 快速使用指南

如果您是 **第一次使用 NexLink Tool**，建议按照以下步骤进行操作。

---

## 2.1 连接设备

1. 使用 **USB** 将 NexLink 设备连接到电脑
2. 打开 **NexLink Tool**

软件启动后可以在 **Setting 页面** 扫描设备。

点击 **Scan** 扫描当前连接的设备。

扫描成功后会在设备列表中显示：

| 信息      | 说明    |
| ------- | ----- |
| Product | 设备型号  |
| Serial  | 设备序列号 |

点击设备即可进行连接。

---

## 2.2 设备连接成功后

设备连接成功后软件会自动执行以下操作：

1. 读取设备 **Firmware Version**
2. 自动执行 **时间同步**
3. 初始化设备事件监听

时间同步用于保证：

* 设备日志时间正确
* 数据记录时间一致

连接成功后界面会提示：

```
Device has been connected
```

---

## 2.3 查看设备屏幕

进入 **Home 页面** 可以：

* 查看设备当前显示画面
* 实时同步设备屏幕
* 导出当前屏幕图像

---

## 2.4 发送控制命令

进入 **Command 页面**

可以：

* 使用预置功能按钮
* 创建自定义命令
* 发送高级命令

---

## 2.5 调试外设接口

进入 **Peripheral 页面**

可以调试设备外设接口：

* UART
* I2C
* GPIO
* SPI

用于硬件调试和通信测试。

---

# 3. 重要说明

## 3.1 工具功能 ≠ 设备全部支持

NexLink Tool 提供较完整的调试功能，但：

**不同设备固件支持的功能可能不同。**

例如：

* 某些设备可能不支持 **SPI**
* 某些设备可能不支持 **屏幕同步**
* 某些设备可能不支持 **UART 事件**

如果设备不支持某个功能：

* 命令可能不会响应
* 或返回错误日志

这属于 **正常情况**。

请以设备固件支持的功能为准。

---

## 3.2 自动时间同步

设备连接成功后软件会自动执行时间同步。

该操作用于校准设备时间。

同步完成后日志时间将保持一致。

---

## 3.3 心跳检测机制

部分设备支持 **Heartbeat（心跳）**。

如果设备支持心跳：

软件会自动检测设备连接状态。

如果 **10 秒内没有收到心跳包**：

软件会自动判定设备断开，并提示：

```
Heartbeat timeout!
```

随后软件会自动：

* 断开设备
* 清理连接
* 停止数据同步

常见原因：

* USB 连接断开
* 设备重启
* 通信异常

---

## 3.4 自动设备释放

如果设备断开或手动取消连接：

软件会自动：

* 关闭设备连接
* 清理事件监听
* 停止屏幕同步
* 清空显示图像

用户无需手动操作。

---

# 4. 软件界面概览

软件主界面包含四个主要页面：

| 页面         | 功能        |
| ---------- | --------- |
| Home       | 显示设备屏幕与日志 |
| Command    | 发送设备命令    |
| Peripheral | 外设接口调试    |
| Setting    | 设备连接与软件配置 |

左侧导航栏用于切换页面。

---

# 5. Home 页面

Home 页面用于 **查看设备显示内容与运行日志**。

---

## 5.1 显示区域

页面上方为设备屏幕的实时显示区域。

功能：

* 实时同步设备屏幕
* 显示当前设备画面
* 支持导出图像

### 右键菜单

在图像区域点击右键可以打开菜单：

| 功能           | 说明        |
| ------------ | --------- |
| Sync Screen  | 开启或关闭屏幕同步 |
| Export Image | 导出当前显示图像  |

导出的图像可用于：

* 调试记录
* 保存截图
* 生成报告

---

## 5.2 日志区域

页面下方为运行日志。

日志包含：

| 字段      | 说明   |
| ------- | ---- |
| Time    | 日志时间 |
| Level   | 日志等级 |
| Message | 日志内容 |

日志等级：

| 等级    | 含义   |
| ----- | ---- |
| Info  | 普通信息 |
| Warn  | 警告   |
| Error | 错误   |

日志用于：

* 查看设备通信状态
* 调试命令执行
* 分析异常情况

---

# 6. Command 页面

Command 页面用于 **发送 NexLink 控制命令**。

页面包含三个模块：

* Functions
* Custom Commands
* Advance Commands

---

## 6.1 Functions

提供常用命令按钮。

| 功能             | 说明       |
| -------------- | -------- |
| SYNC Time      | 同步设备时间   |
| GetDisplayInfo | 获取显示设备信息 |
| Show Picture   | 显示图片     |

点击按钮即可发送对应命令。

---

## 6.2 Custom Commands

用户可以创建 **自定义命令按钮**。

特点：

* 支持拖拽排序
* 点击按钮即可发送命令
* 支持删除命令

### 删除命令

右键点击按钮选择：

```
Delete
```

即可删除该命令。

---

## 6.3 Advance Commands

高级命令允许用户手动输入完整命令。

每条命令包含：

| 字段   | 说明   |
| ---- | ---- |
| Name | 命令名称 |
| Cmd  | 命令类型 |
| Data | 命令数据 |

操作按钮：

| 按钮     | 功能   |
| ------ | ---- |
| Send   | 发送命令 |
| Delete | 删除命令 |

点击 **Add Command** 可以新增命令。

---

# 7. Peripheral 页面

Peripheral 页面用于 **调试设备外设接口**。

支持以下接口：

* UART
* I2C
* GPIO
* SPI

---

## 7.1 UART 操作

UART 用于串口通信测试。

可配置：

| 参数       | 说明   |
| -------- | ---- |
| Channel  | 串口通道 |
| Baudrate | 波特率  |

操作：

| 按钮   | 功能    |
| ---- | ----- |
| Init | 初始化串口 |
| Send | 发送数据  |
| Test | 测试通信  |

发送数据后日志窗口会显示通信结果。

---

## 7.2 I2C 操作

I2C 用于调试 I2C 设备。

可配置：

| 参数      | 说明     |
| ------- | ------ |
| Channel | I2C 通道 |
| Clock   | I2C 时钟 |

每个操作包含：

| 字段    | 说明    |
| ----- | ----- |
| Slave | 从机地址  |
| Reg   | 寄存器地址 |
| Size  | 读取长度  |
| Data  | 写入数据  |

操作：

| 按钮        | 功能    |
| --------- | ----- |
| Write     | 写入数据  |
| WriteRead | 写入并读取 |

---

## 7.3 GPIO 操作

GPIO 用于控制设备引脚。

可配置：

| 参数   | 说明      |
| ---- | ------- |
| Port | 端口      |
| Pin  | 引脚      |
| Mode | 工作模式    |
| Pull | 上拉 / 下拉 |

操作：

| 按钮   | 功能       |
| ---- | -------- |
| INIT | 初始化 GPIO |
| HIGH | 输出高电平    |
| LOW  | 输出低电平    |
| READ | 读取电平     |

电平状态通过指示灯显示：

* 绿色：高电平
* 灰色：低电平

---

## 7.4 SPI 操作

SPI 用于 SPI 设备通信测试。

可配置：

| 参数         | 说明     |
| ---------- | ------ |
| Channel    | SPI 通道 |
| Clock      | SPI 时钟 |
| Mode       | SPI 模式 |
| Byte Order | 字节顺序   |

操作：

| 按钮        | 功能      |
| --------- | ------- |
| Init      | 初始化 SPI |
| Write     | 写入数据    |
| WriteRead | 写入并读取   |

日志窗口用于显示通信结果。

---

# 8. Setting 页面

Setting 页面用于设备管理与软件配置。

功能包括：

* 扫描设备
* 连接设备
* 断开设备
* 切换软件主题

# 9. 常见问题

### 无法连接设备

请检查：

* USB 连接是否正常
* 驱动是否正确安装
* 设备是否已上电

---

### 无法发送命令

可能原因：

* 设备未连接
* 通信接口未初始化
* 命令格式错误

---

### 屏幕不同步

请确认已开启：

```
Sync Screen
```

---

# 10. 使用建议

推荐使用流程：

1. 连接设备
2. 打开软件
3. 进入 **Setting 页面** 扫描并连接设备
4. 使用 **Command 页面** 控制设备
5. 在 **Home 页面** 查看显示效果
6. 使用 **Peripheral 页面** 调试外设
